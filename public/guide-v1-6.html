01

Prepare the workspace

Jalankan SQL upgrade v1.5 → v1.6, deploy seluruh source ke Vercel, lalu buka Knowledge Desk dari sidebar Focusdesk.

Environment, bot, dan pairing lama tetap digunakan. Tidak perlu API AI tambahan.

02

Define ownership

Buat kategori dan priority. Tambahkan aplikasi, PIC utama/cadangan, lalu aturan PIC per kategori. Application owner menjadi reviewer.

Hubungkan hanya grup yang boleh membaca panduan aplikasi tersebut.

03

Publish knowledge

Impor Markdown, isi kata kunci, periksa langkah-langkahnya, lalu ubah Draft menjadi Published. Bot menyampaikan kutipan dan revisi sumber.

Isi panduan asli perlu disediakan admin aplikasi.

Activity trail

    Commands

    /apps
    Menampilkan aplikasi yang boleh diakses di grup.

    /ask GEE pertanyaan
    Mencari bagian panduan Published.

    Reply pesan bot untuk menambahkan informasi. Jika ada beberapa bot, gunakan command dengan @username_bot.

    Report integrity

    Pelapor hanya dapat bertindak pada laporan sendiri di grup asal. Semua orang dapat melihat tombol grup, tetapi server membatasi pelaksanaannya.

    Konfirmasi berulang tidak menggandakan task. Koreksi dicatat terpisah; pertanyaan asli tetap utuh.

    Execution & review

    Kartu execution dikirim pribadi ke PIC. Start Work mengubah status task; Need Testing meneruskan ke reviewer.

    Reviewer meluluskan atau mengembalikan ke Rework. Feedback pelapor tidak otomatis mengambil alih persetujuan reviewer.

    Daily schedule

    09.00 WIB: ringkasan grup dan kartu pribadi PIC. 17.30 WIB: pekerjaan tertunda dan agenda besok.

    Worker berjalan setiap menit saat sehat. Periksa cron active, log eksekusi, HTTP response terbaru, dan last_tick pada dua waktu berbeda. Keberhasilan request manual saja belum membuktikan scheduler aktif.

    Release boundaries

    Versi ini memakai pencarian kata kunci dan kutipan Markdown, tanpa LLM. Reviewer adalah application owner. Critical support tampil High di board lama. Target memakai jam kalender; SLA escalation otomatis belum tersedia. File/foto Telegram, merge laporan terpisah, dan draft knowledge otomatis dari resolusi belum tersedia.

    Reports memiliki pagination 50 baris dan export CSV halaman. Laporan task bulanan tetap memakai Monthly reports. Baca README dan docs/KNOWLEDGE_DESK.md dalam ZIP untuk pemasangan lengkap.

    Focusdesk 1.6 · Prototype demo tidak mengirim Telegram atau mengubah Supabase.
