Bot menerima pesan. AI menyusun jawaban dari panduan. Focusdesk menyimpan laporan dan pekerjaan.

1. Apa yang terhubung?

Telegram botMenerima /ask dan tombol. Bot lama dari BotFather tetap dipakai.
OpenAI APIMenyusun jawaban dari maksimal tiga kutipan Published yang boleh diakses grup.

ChatGPT dalam percakapan ini tidak menjadi anggota grup Anda. Integrasi berjalan melalui OpenAI API di server Focusdesk.

2. Upgrade SQL dan aplikasi

  1. Backup database dan source deployment lama.
  2. Sudah v1.6: jalankan Focusdesk_v1_6_to_v1_7.sql seluruhnya di Supabase SQL Editor.
  3. Masih v1.3–v1.5: gunakan Focusdesk_Upgrade_to_v1_7.sql dari ZIP. Database kosong saja memakai Focusdesk_Supabase_v1_7.sql.
  4. Ekstrak ZIP dan ganti isi root repository, termasuk api/, server/, public/, package.json dan konfigurasi build. Jangan hanya upload FE.
  5. Tambahkan environment berikut, lalu redeploy Production.

Migration tidak menghapus task, user, PIC atau pairing Telegram. Worker yang sudah aktif mulai memproses antrean setelah deployment.

3. Pasang API key di Vercel

Cabut key yang pernah dibagikan di chat. Buat key baru di project OpenAI, lalu simpan langsung di Vercel → project Focusdesk → Settings → Environment Variables → Production.

NamaIsi
OPENAI_API_KEYKey baru project OpenAI
OPENAI_ENABLEDtrue
OPENAI_MODELgpt-4.1-mini
OPENAI_DAILY_LIMIT100; opsional, batas 1–500/workspace/hari WIB

Jangan beri prefix PUBLIC/VITE/NEXT_PUBLIC pada key. Jangan menaruh key di HTML, Markdown, GitHub atau Vault cron. CRON_SECRET dan TELEGRAM_BOT_TOKEN tetap memakai nilai yang sudah berfungsi.

Redeploy setelah menyimpan environment. Pastikan billing/quota API dan akses model project tersedia. Saat AI aktif, pertanyaan serta kutipan panduan dikirim ke OpenAI dengan store:false; ini bukan janji zero-retention seluruh layanan.

4. Periksa di Workspace

  1. Login admin → Workspace → Telegram & AI assistant.
  2. Periksa status key, toggle server, model dan penggunaan hari ini pada halaman AI & Telegram.
  3. Klik Periksa koneksi AI. Tes membaca akses model tanpa mengirim dokumen/generasi; uji /ask tetap diperlukan untuk memastikan jawaban lengkap.
  4. Bot/domain yang sama tidak membutuhkan pairing atau setWebhook ulang. Jika belum terhubung, buka Settings & Telegram, pasang environment BotFather, daftarkan webhook dan hubungkan personal/grup dengan kode yang dibuat Focusdesk.
  5. Pastikan aplikasi aktif, Group access sesuai, dan artikel Published.

Pelapor grup tidak wajib login web. PIC harus memiliki akun dan pairing pribadi untuk menerima serta menjalankan kartu eksekusi.

Terbantu → pertanyaan selesai. Belum membantu / tambah detail → reply teks. Buat laporan → pilih kategori → konfirmasi → task ke PIC. AI tidak mengubah task, memberikan akses, atau memutuskan hasil UAT.

Jika jawaban belum memakai AI
Kutipan panduan (mode pencarian)AI mati atau key belum terpasang. Periksa environment dan redeploy.
AI belum tersediaPeriksa aktivitas jawaban: batas harian, quota, key ditolak, model atau timeout.
Panduan belum cukupLengkapi artikel/kata kunci, tambahkan detail atau buat laporan.
Pesan menungguPastikan worker satu-menit aktif. Maksimal satu pesan support per invocation saat AI aktif; antrean dapat menunda jawaban.
Function tidak ditemukanJalankan SQL upgrade v1.7 secara lengkap, lalu refresh.

Batasan & rollback AI

Retrieval masih memakai kata kunci PostgreSQL, belum embeddings. Bot tidak menanggapi semua obrolan bebas; gunakan /ask di grup. Kutipan sumber tidak menjamin setiap kalimat AI benar; lakukan UAT dengan panduan asli.

Set OPENAI_ENABLED=false lalu redeploy untuk kembali ke kutipan panduan. Jangan menghapus tabel atau rollback SQL. Scheduler existing 09:00 dan 17:30 WIB tetap berlaku.
